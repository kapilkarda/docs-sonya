The Purpose because of which an agent is created is referred to as the goal of the agent.

Agents while engaging with your contacts on call will try to full fill their respective goal that has been assigned to them

## Example Of Valid Goals :

✔ Inform contacts about the upcoming sale

✔ Take Customers Feedback

✔ Get Test Drive Booking

## Steps to Set Up Goal of an Agent :

Click on the <span style={{ color: "#ca8a04" }}>Agent</span> you want to add goal for.

Fill in the <span style={{ color: "#ca8a04" }}>Goal</span> of the Agent in the text box provided.

Click on "<span style={{ color: "#ca8a04" }}>Save</span>" on Edit Agent Page.

<span style={{ fontWeight: 800 }}>
  You have successfully added Goal for your Agent !! 👏👏
</span>
