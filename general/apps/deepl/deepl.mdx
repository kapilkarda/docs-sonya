
1. Go to [your account page](https://www.deepl.com/account/summary) on DeepL.
2. Scroll down and copy `Authentication Key for DeepL API`.
3. Paste the key into the `Authentication Key` field in Bolify AI.
4. Write any screen name to be displayed in Bolify AI.
5. Click `Save`.
6. Start using DeepL integration with Bolify AI!
